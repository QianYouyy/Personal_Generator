# 分步实施路线图

## Phase 1: 基础环境 & 数据准备（预计 1-2 天）

### Step 1.1: 环境搭建
- [ ] 确认 Python 版本 (>=3.10)
- [ ] 安装依赖 `pip install -r requirements.txt`
- [ ] 配置 API Key（OpenAI / 本地 LLM）
- [ ] 测试 Concordia 库安装

### Step 1.2: 问卷生成器 (QGenerator)
- [ ] 实现 LLM 调用封装（支持 GPT-4o / 本地模型）
- [ ] 实现两阶段生成 pipeline：
  1. `ĉ → c + D`（扩展上下文 + 提议多样性轴）
  2. `c, D → I`（按轴生成 Likert 题项）
- [ ] 输出 Concordia 兼容的 Question 对象
- [ ] 运行生成 50 份问卷
- [ ] 划分 train/val/test（30/10/10）

> **用户介入点**: 需要审核生成的 50 份问卷质量，确认多样性轴是否合理

### Step 1.3: 种子人格生成器（3 个 seed）
- [ ] 实现 Stage 1（串行高层标签生成）
- [ ] 实现 Stage 2（并行细节扩展）
- [ ] 分别实现 3 个 seed 的变体策略
- [ ] 单测：验证生成的人格文本质量

> **用户介入点**: 确认 3 个 seed 的生成效果，是否符合预期

---

## Phase 2: 模拟与评估（预计 2-3 天）

### Step 2.1: Concordia 模拟器
- [ ] 封装 Concordia Agent 创建
- [ ] 实现"适当性逻辑"回答流程
- [ ] 实现每题后记忆重置
- [ ] Likert 回答 → 数值编码
- [ ] 按轴取平均 → z_i

> **用户介入点**: 抽样检查 Agent 回答是否符合人格描述

### Step 2.2: 多样性评估器
- [ ] 实现 Coverage（蒙特卡洛撒点 + 球覆盖）
- [ ] 实现 ConvexHull Volume（scipy）
- [ ] 实现 Avg/Min Pairwise Dist
- [ ] 实现 Dispersion（最大空白区）
- [ ] 实现 KL Divergence（vs Sobol 分布）
- [ ] Coverage 半径 k 校准（1000 次 Sobol 实验）
- [ ] 适应度聚合：40 份问卷平均 + 符号统一

> **用户介入点**: 确认各指标权重或是否有额外指标需求

### Step 2.3: 端到端验证
- [ ] 用 seed1 跑通完整 pipeline
- [ ] 验证输出格式和数据流

---

## Phase 3: Open-Evolve 进化引擎（预计 3-5 天）

### Step 3.1: 岛屿系统
- [ ] 实现 Island 类（维护 6 个精英位）
- [ ] 初始种子轮询分配（seed1×4, seed2×3, seed3×3）

### Step 3.2: 变异算子 (Mutator)
- [ ] 构建提示词库（附录 B 风格）
- [ ] 实现 LLM 代码改写器
- [ ] 约束校验：只改 Stage 1/2 内部逻辑

> **用户介入点**: review 并补充变异提示词库

### Step 3.3: 评估与选择
- [ ] 候选 φ' 评估：40 问卷 × 25 人格
- [ ] 精英更新规则（任一指标打破纪录即上位）

### Step 3.4: 周期性灭绝
- [ ] 每 100 轮 / 8 小时触发
- [ ] 差岛重置：从最优岛复制精英

### Step 3.5: 反馈机制
- [ ] 迭代间观察：随机子集的人格 + 分数
- [ ] LLM 基于 empirical data 指导改进

---

## Phase 4: 集成 & 调优（预计 2-3 天）

### Step 4.1: 主循环
- [ ] 整合 5 层 pipeline

- [ ] 日志与监控

### Step 4.2: 性能优化
- [ ] 并行化（问卷间、人格间）

- [ ] 进化曲线（各指标随轮数变化）
- [ ] 岛屿热力图

> **用户介入点**: 确认可视化需求优先级

## 风险与备选方案

| 风险 | 影响 | 备选方案 |
|------|------|----------|
| Concordia 安装困难 | 阻塞 Phase 2 | 自研简化版模拟器（仅 Likert 回答逻辑） |
| gemma-3-27b 显存不足 | 阻塞生成 | 换更小模型（如 4B/9B）或 API 替代 |
| LLM API 成本过高 | 进度慢 | 本地部署 + 批量生成 |
| 进化收敛慢 | 效果差 | 调整变异强度 / 增加反馈频率 |
